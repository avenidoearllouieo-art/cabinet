# TapTrack Render Deployment

The root `render.yaml` is now the temporary free-testing Blueprint. It configures only the React `frontend`, Django `backend`, and a free Render PostgreSQL database. `cabinet`, Raspberry Pi services, and ESP32 firmware are not included. The free resources use distinct `*-free-test` names so syncing this Blueprint creates separate test resources instead of downgrading or detaching storage from production resources. The previous paid production configuration is preserved separately in [`render.paid.yaml`](render.paid.yaml); do not sync that file for free testing.

## Free Testing Configuration

**Django API**

- Root directory: repository root (`.`), because `requirements.txt` is at the repository root.
- Build command: `bash backend/build.sh`
- Start command: `python backend/manage.py migrate --noinput && mkdir -p "${DJANGO_MEDIA_ROOT:-/tmp/taptrack-media}" "${DJANGO_FILE_UPLOAD_TEMP_DIR:-/tmp/taptrack-tmp}" && gunicorn --chdir backend config.wsgi:application --bind 0.0.0.0:$PORT`
- Settings / WSGI: `config.settings` / `config.wsgi:application`
- Plan: `free`; no persistent disk is configured.

On the free plan Render does not support a pre-deploy command, so the existing migration command runs at service startup before Gunicorn. Migrations are repeatable schema updates; they do not import, flush, or delete database records.

**React static site**

- Root directory: `frontend`
- Build command: `npm ci && npm run build`
- Publish directory: `dist` in the Dashboard (`frontend/dist` in the root Blueprint, which is repo-root-relative).
- The existing `BrowserRouter` is supported by a `/*` rewrite to `/index.html`.

## Required Environment Variables

The Blueprint generates `DJANGO_SECRET_KEY` and connects `DATABASE_URL` to the free PostgreSQL resource. Fill in the frontend and API hostnames when prompted by Render:

| Service | Variable | Value |
| --- | --- | --- |
| API | `DJANGO_DEBUG` | `false` |
| API | `DJANGO_SECRET_KEY` | Generated by Render; keep it secret |
| API | `DATABASE_URL` | Free Render PostgreSQL internal connection string |
| API | `DJANGO_CORS_ALLOWED_ORIGINS` | `https://<frontend-host>` (origin only) |
| API | `DJANGO_CSRF_TRUSTED_ORIGINS` | `https://<frontend-host>` (include scheme, no path) |
| API | `TAPTRACK_NFC_REGISTRATION_URL_BASE` | `https://<frontend-host>/register` |
| Frontend | `VITE_API_BASE_URL` | `https://<api-host>/api` |

The API also sets testing-only filesystem paths in the Blueprint: `DJANGO_MEDIA_ROOT=/tmp/taptrack-media` and `DJANGO_FILE_UPLOAD_TEMP_DIR=/tmp/taptrack-tmp`. The API hostname is automatically added to `ALLOWED_HOSTS`. If deployed NFC readers are part of the test, add `TAPTRACK_NFC_DEVICE_MAP` as a secret using the existing test-device mapping. `DEVICE_API_KEY` is only for development mock mode; it is not used as a production device credential. Add custom hostnames through `DJANGO_ALLOWED_HOSTS` if needed.

The Blueprint uses `sync: false` for origin/URL/reader values. Render prompts for them on initial Blueprint creation; for an already-created Blueprint, configure them in the Render dashboard.

## Free-Tier Data And Upload Warning

**This configuration is for temporary capstone testing only. Do not use real student records, production credentials, or real student media.**

- Free Web Services have an ephemeral filesystem. Uploaded activity attachments, student submission videos/files, and upload temporary files are stored under `/tmp` and can disappear when the service restarts, spins down after 15 idle minutes, or redeploys. The app's upload functionality is still enabled; only the durability guarantee is absent.
- Do not transfer or migrate real `backend/media` contents to this free service. Test only with disposable, non-sensitive files.
- Free PostgreSQL has 1 GB storage, no backups, and expires 30 days after creation. After expiration there is a 14-day upgrade grace period; after that Render deletes the database and its data. Do not migrate production accounts or records into it.
- A free API service can take about a minute to spin back up, may restart, and shares the workspace's 750 free instance-hours per month. Static sites are free; bandwidth/build-pipeline overages can suspend free services if no payment method is present.
- The current API accepts videos up to 500 MB and submissions up to 750 MB combined. Render ingress/request limits, available ephemeral disk, and free service resource limits may prevent the largest uploads. Test with disposable small files first; large-upload testing is not guaranteed on this plan.

If tests require reliable uploads, retained data, or larger video bodies, use a paid API with persistent storage or a separate object-storage upload design. That is outside this free-testing configuration.

## Local Safety

Without `DATABASE_URL`, Django continues to use local `backend/db.sqlite3` and `backend/media`. The free Blueprint changes only Render-provided media/temp environment values; it does not change models, migrations, permissions, or upload handling. Do not use the free PostgreSQL database as the destination for a production-data migration.
