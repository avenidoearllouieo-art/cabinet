# TapTrack Kiosk Prototype

This standalone React application demonstrates a touch-friendly NFC cabinet workflow. It simulates card registration, participant scanning, station selection, and cabinet open/close sessions using browser local storage.

```powershell
npm ci
npm run dev
```

This prototype does not call the TapTrack API or control physical hardware. Treat all cabinet actions as simulations until a hardware API and audit policy are implemented.
